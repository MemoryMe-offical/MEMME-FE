-----
<상태 관리>

로컬 상태: 해당 컴포넌트 한정 정보(useState), 예를 들어 인풋 값, 모달 열림/닫힘 여부

전역 상태: 앱 전체에서 관리되는 정보(react context, redux 등), 예를 들어 로그인 유저 정보, 토큰, 다크모드 등

useReducer: useState보다 더 규칙적인 방식으로 상태를 바꾸는 도구. 상태가 단순히 count 하나만이 아니라, {loading, error, data} 등 여러 필드를 가진 객체를 정리

React Context란: 기존에는 파일 간에 값을 props를 통해 계속 넘겨줘야 됨, Context를 쓰면 App에서 한 번으로 전역에 값 제공하고 아무데서나 꺼내쓸 수 있음

-----
<데이터 관리>

전역 상태: 지금 실행 중인 앱에서만 필요한 정보(로그인 유저 정보, 필터 값 등)

로컬 스토리지: 앱을 끄거나 켜도 다시 복원해야 하는 정보(자동 로그인용 토큰, 마지막으로 본 온보딩 여부 등)

<기본 컴포넌트>

View, Text, TextInput, ScrollView, FlatList, Pressable / TouchableOpacity, Image

<타입>

문자: string
숫자: number
참/거짓: boolean
아직 값이 없는 것들: null / undefined
    - let userName: string | null = null; // 지금은 값이 없지만 후에 string으로 들어올 값
    - let selectedid: number | undefined; // 아직 선택 안되었을 수도 있고, 되면 number로

-----
<타입 사용 예시>

// 기본
const [count, setCount] = useState<number>(0);
const [email, setEmail] = useState<string>('');
const [loading, setLoading] = useState<boolean>(false);
const [errorMessage, setErrorMessage] = useState<string | null>(null);

// 객체
type Todo = {
  id: number;
  title: string;
  done: boolean;
};

const [todos, setTodos] = useState<Todo[]>([]); // 또는
const [todos, setTodos] = useState<Todo[]>({
    id: 0,
    title: "",
    done: false,
});
